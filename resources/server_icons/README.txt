Add individual server icons here: default.png, halloween.png, bonfire.png, etc.
The lowercase filename (without extension) is the theme name.
Supported extensions: .png, .jpg, .jpeg, .webp. Maximum input size: 8 MiB.
Files take precedence over Discord uploads with the same theme name.
After deploying, use /servericon set theme:auto to enable the schedule.
See the Seasonal server icons section in the project README for dates and commands.
